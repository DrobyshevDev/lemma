# Пререквизиты

Курс рассчитан на человека, который **не знает ни машинного обучения, ни высшей
математики**. Всё, что нужно, вводится по ходу и ровно тогда, когда становится нужным.

Но кое-что курс всё-таки не объясняет, потому что это объяснено лучше в других местах.

## Что нужно уметь до начала

### Python на уровне «пишу и отлаживаю сам»

Переменные, списки и словари, циклы, функции, классы на уровне «понимаю, что это такое»,
чтение чужого кода без паники. Виртуальные окружения и `pip install`.

Не нужно: декораторы, метаклассы, асинхронность, дескрипторы.

Проверка: если вы можете за полчаса написать функцию, которая читает CSV, считает среднее
по колонке и рисует гистограмму, — этого достаточно.

### Командная строка

Перейти в каталог, запустить скрипт, посмотреть вывод, понять сообщение об ошибке.

### git

`clone`, `commit`, `push`, ветка, pull request. Без этого не сделать выпускную работу и не
опубликовать воспроизведение.

## Чего делать **не** нужно

Не нужно проходить курс по линейной алгебре перед началом. Это самая частая ошибка: люди
тратят три месяца на абстрактную алгебру, забывают её и приходят на ML с ощущением, что
уже устали. В модуле 3 линейная алгебра вводится через регрессию и PCA — то есть вы сразу
видите, зачем нужна каждая операция.

То же с теорией вероятностей и матанализом.

## Где взять недостающее

Python, алгоритмы, работа с данными и SQL хорошо разобраны в курсах Евгения Денисовича
Лебедева (МИИГАиК), на [ratcatcher.ru](https://ratcatcher.ru/):

- [Информатика](https://ratcatcher.ru/media/inf_robo/main.html) — основы и Python.
- [Алгоритмизация](https://ratcatcher.ru/alg) — алгоритмическое мышление, сложность.
- [Управление данными](https://ratcatcher.ru/bd) — реляционные БД, SQL, нормализация,
  пространственные данные и PostGIS.

Этот курс намеренно **не переписывает** их своими словами. Если вы уже прошли что-то из
перечисленного — пропускайте соответствующие темы; если нет — идите туда и возвращайтесь.
Материалы используются с разрешения автора.

!!! tip "Про SQL"
    SQL пригодится не в первых модулях, а в частях V и VII, когда данные перестанут
    помещаться в один CSV. Начинать курс без SQL можно; заканчивать — уже нет.

## Техника

| | Минимум | Комфортно |
|---|---|---|
| Части I–II | любой ноутбук | — |
| Части III–IV | Colab с бесплатной GPU | своя GPU от 8 ГБ |
| Части V–VI | Colab | 16 ГБ VRAM для LLM-модулей |

Каждый ноутбук курса устроен так, чтобы **запускаться на CPU за разумное время** —
на уменьшенных данных, с честной пометкой, какое число получится на полном прогоне.
Отсутствие видеокарты не должно останавливать обучение; оно должно замедлять эксперименты.
